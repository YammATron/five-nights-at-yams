# Five Nights at Yams

A browser horror parody with five nights, four Yams, seven cameras, two doors,
lights, limited power, and saved progress.

## Play

Open `index.html` in a modern browser, or play through the GitHub Pages link.
Keep the scripts, styles and assets together. No build step is required.

Q/E: left/right door. A/D: left/right light. C/Space: camera monitor.
1-7: camera feeds. Arrow keys: look around. Escape: pause.
The visible buttons also work with mouse or touch.

## Publish with GitHub Pages

Upload the contents of this folder, keeping `index.html` at the repository root
and preserving the `assets` folder. Include `.nojekyll`.
In Settings > Pages, select Deploy from a branch, main, /(root), and save.
Share the published link after the deployment finishes.

## Local data

Progress saves in this browser's local storage. There are no accounts, analytics,
trackers or external network services. The game does not upload player data.

The character photos and recordings are included game assets and are visible
to anyone with access to the published game or repository.
Artwork includes AI-edited character portraits and AI-generated room backgrounds.
